# সহজ সমাধান — Starter E-commerce Frontend

এই ZIP একটি **working starter frontend**। এতে public product catalogue, search/filter, product details, order form এবং WhatsApp order flow আছে।

## গুরুত্বপূর্ণ
এটি এখনও production-ready private Admin + database + image storage system নয়। Browser localStorage ব্যবহার করা হয়েছে যাতে আপনি প্রথমে UI/flow পরীক্ষা করতে পারেন।

## চালানো
`index.html` ব্রাউজারে খুলুন।

## WhatsApp
Order button আপনার দেওয়া নম্বর `01710441658`-এর WhatsApp compose screen খুলবে।

## Production version
পরবর্তী ধাপে secure Admin authentication, real database, image storage এবং server-side order management যুক্ত করতে হবে। Secrets frontend-এ রাখা যাবে না।
